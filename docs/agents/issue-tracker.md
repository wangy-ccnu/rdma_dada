# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues. Use the `gh` CLI for all
operations.

## Repository

- GitHub repository: `wangy-ccnu/rdma_dada`
- Remote: `git@github.com:wangy-ccnu/rdma_dada.git`
- Multi-server changes target `codex/multi-server-observation`; paper/ablation
  branches retain their scope. Confirm checkout and remote before publishing.
  Documentation maintenance does not authorize issue or PR creation.

## Conventions

- Create issues with `gh issue create`.
- Read issues and comments with `gh issue view <number> --comments`.
- List issues with `gh issue list`.
- Comment with `gh issue comment`.
- Apply or remove labels with `gh issue edit`.
- Close issues with `gh issue close`.

Infer the repository from the current Git checkout.

## Pull requests as a triage surface

**PRs as a request surface: no.**

## Skill operations

When a skill says "publish to the issue tracker", create a GitHub issue.

When a skill says "fetch the relevant ticket", read the corresponding GitHub
issue, including its labels and comments.
